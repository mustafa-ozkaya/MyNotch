# Contributing

Thanks for your interest in MyNotch! It's a small personal project, so please open an issue before
starting on anything big, so we can agree on the approach first.

## Bugs and feature requests

Open an [issue](https://github.com/mustafa-ozkaya/MyNotch/issues) with your macOS version, your Mac
model, the MyNotch version (**Settings › About**), and the steps to reproduce. Screenshots or a short
screen recording help a lot.

If the problem also happens in [boring.notch](https://github.com/TheBoredTeam/boring.notch), it's
probably in code MyNotch inherited, and reporting it there helps everyone.

## Pull requests

1. Fork the repo and create a branch from `main`.
2. Build and run as described in the [README](README.md#building-from-source).
3. Keep changes focused, and match the style of the surrounding code.
4. Run the tests (**Product › Test**, or `xcodebuild test -scheme boringNotch` in `boringnotch/`)
   and make sure they pass.
5. Describe what you changed and how you tested it.

By contributing, you agree that your contributions are licensed under the GPL-3.0, like the rest
of the project.
