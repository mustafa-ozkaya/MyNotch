# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[Report a vulnerability](https://github.com/mustafa-ozkaya/MyNotch/security/advisories/new) form
rather than in a public issue. I'll reply as soon as I can and keep you posted on the fix.

Issues in code that MyNotch inherits from [boring.notch](https://github.com/TheBoredTeam/boring.notch)
are worth reporting upstream as well. Report issues in third-party dependencies to their maintainers.

## Supported versions

Only the latest release gets fixes.
